# App Store 地区快速切换（国区 ⇄ 美区）

## 先说清楚：这个快捷指令能帮你做什么

苹果**不允许**快捷指令登录或退出 Apple ID，所以没有任何快捷指令能做到“点一下就换号”。

这个快捷指令做的是：**你点一下，选一个账号 → 它把这个账号的邮箱复制好 → 自动打开 App Store**。
你只需要在 App Store 里点“退出登录”，再粘贴邮箱、用 Face ID 填密码登录。

---

## 第一部分：制作快捷指令（只需做一次，约 3 分钟）

整个快捷指令只有 **4 个操作**，从上到下排列，不需要拖动、不需要设置变量。

### 第 1 步：新建快捷指令

1. 打开 iPhone 上的 **“快捷指令”** App（白色和彩色叠在一起的图标）。
2. 点屏幕底部的 **“快捷指令”** 标签。
3. 点右上角的 **“+”**，进入一个空白的编辑页面。
4. 点页面最上方的标题 **“新快捷指令”** → 选 **“重命名”** → 输入 `切换App Store账号` → 点键盘上的 **“完成”**。

### 第 2 步：添加“列表”操作（存放两个账号）

1. 点屏幕底部的搜索框 **“搜索操作”**，输入 `列表`。
2. 在结果里点 **“列表”**（图标是灰色的，不要选“从列表中选取”）。
3. 页面上出现一个“列表”方块，里面默认有两行：**“一”** 和 **“二”**。
4. 点 **“一”**，删掉文字，输入你的**国区 Apple ID 邮箱**。
5. 点 **“二”**，删掉文字，输入你的**美区 Apple ID 邮箱**。

> 只填邮箱，**不要填密码**。

### 第 3 步：添加“从列表中选取”操作（运行时让你选账号）

1. 再点底部搜索框，输入 `从列表中选取`。
2. 点 **“从列表中选取”**。
3. 它会自动出现在“列表”下面，并显示 **“从 列表 中选取”**，表示它已经自动连上了上一步，**不用改任何东西**。

### 第 4 步：添加“拷贝至剪贴板”操作（复制选中的邮箱）

1. 点底部搜索框，输入 `拷贝`。
2. 点 **“拷贝至剪贴板”**。
3. 它显示为 **“将 所选项目 拷贝至剪贴板”**，同样**不用改**。

### 第 5 步：添加“打开 App”操作（自动打开 App Store）

1. 点底部搜索框，输入 `打开App`。
2. 点 **“打开App”**。
3. 方块里显示 **“打开 App”**，其中蓝色的 **“App”** 两个字可以点：点它 → 在列表中找到并选择 **“App Store”**。
4. 现在方块显示为 **“打开 App Store”**。

### 第 6 步：保存

点右上角的 **“完成”**。快捷指令就做好了。

### 做完后应该长这样

从上到下一共 4 个方块：

```
┌─────────────────────────────────┐
│ 列表                            │
│   · 你的国区邮箱                │
│   · 你的美区邮箱                │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│ 从 列表 中选取                  │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│ 将 所选项目 拷贝至剪贴板        │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│ 打开 App Store                  │
└─────────────────────────────────┘
```

## 第二部分：准备密码（只需做一次）

为了登录时不用手打密码，把两个账号存进系统的“密码”App：

1. 打开 **“密码”** App（iOS 18 及以上；旧系统在“设置 → 密码”）。
2. 点 **“+”** 新建。
3. **网站**填 `apple.com`，**用户名**填 Apple ID 邮箱，**密码**填对应的密码 → 存储。
4. 国区、美区两个账号各存一次。

---

## 第三部分：每次切换账号怎么操作

假设你现在登录的是国区，想换成美区：

1. **运行快捷指令**：在快捷指令 App 里点一下 **“切换App Store账号”**。
2. **选账号**：弹出两个邮箱，点**美区那个邮箱**。邮箱已被复制，App Store 自动打开。
3. **退出旧账号**：在 App Store 里点**右上角的圆形头像** → 一直滑到页面**最底部** → 点 **“退出登录”**。
4. **登录新账号**：
   1. 再点一次右上角的头像，出现登录界面。
   2. 长按账号输入框 → 点 **“粘贴”**，邮箱就填好了。
   3. 点密码框，键盘上方会出现 **“密码”/钥匙** 提示 → 点它 → 用 Face ID 验证 → 密码自动填好。
   4. 点 **“登录”**。

完成。想换回国区，重复一遍，第 2 步选国区邮箱即可。

> **注意：** 只在 **App Store** 里退出，**不要**去“设置”最上面退出你的 Apple ID（那是 iCloud）。
> 在 App Store 里换号不会影响 iCloud、照片、通讯录和备份。

## 第四部分：让它更好点（可选）

| 方式 | 怎么设置 | 以后怎么用 |
| --- | --- | --- |
| 放到主屏幕 | 快捷指令 App 里**长按**这个快捷指令 → **分享** → **添加到主屏幕** → 添加 | 主屏幕点图标 |
| 轻点手机背面 | **设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下** → 往下滑，选这个快捷指令 | 用手指敲手机背面两下 |
| 控制中心（iOS 18+） | 从右上角下拉控制中心 → 左上角 **“+”** → **添加控制** → 搜 `快捷指令` → 选这个快捷指令 | 下拉控制中心点按钮 |
| Siri | 不用设置 | 说“切换App Store账号” |

## 常见问题

**运行后没弹出选择框？**
检查第 2 步的“列表”里是不是确实填了两行邮箱，以及第 3 步显示的是“从 列表 中选取”。

**找不到“退出登录”？**
它在 App Store 头像页面的**最底部**，需要往下滑很久。也可以走另一条路：**设置 → 点最上面你的名字 → 媒体与购买项目 → 退出登录**，效果一样，只退出 App Store 账号。

**换号后，之前装的 App 会被删除吗？**
不会。App 会一直保留，更新时会让你输入下载它的那个账号的密码。

**美区账号怎么付费？**
需要美区付款方式，常见做法是买美区 App Store 礼品卡，切到美区账号后在 App Store 头像页里点“兑换充值卡或代码”。
