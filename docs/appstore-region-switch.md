# App Store 地区快速切换（国区 ⇄ 美区）

用一个快捷指令在中国大陆和美区两个 Apple ID 之间切换 App Store 账号。

## 能做到什么，做不到什么

苹果没有给快捷指令开放“登录或退出 Apple ID”的操作，任何快捷指令都无法全自动换号。所以这个快捷指令负责把能省的步骤都省掉：

| 步骤 | 谁来做 |
| --- | --- |
| 选择要切到哪个区 | 快捷指令（弹出菜单） |
| 把目标账号复制到剪贴板 | 快捷指令 |
| 打开 App Store | 快捷指令 |
| 点头像，退出登录 | 你（点两下） |
| 粘贴账号，输入密码或用密码自动填充 | 你 |

快捷指令里**只保存账号邮箱，不保存密码**。快捷指令里的文本是明文，存密码不安全。密码请交给系统自带的“密码”App，登录时用 Face ID 自动填充。

## 准备工作

1. 确认两个账号都保存在“密码”App 里（没有的话手动添加，网站填 `apple.com`）。这样登录时可以直接用 Face ID 自动填充密码。
2. **只在 App Store 里换号，不要退出 iCloud。** iCloud 一直用你的主账号，照片、通讯录、备份都不受影响。

## 制作步骤

在 iPhone 上打开“快捷指令”App，点右上角 `+` 新建，名字填 **切换 App Store 地区**，然后按顺序添加下面的操作：

1. **文本**：填国区 Apple ID 邮箱。
   点这个操作的输出，**重命名**为 `国区账号`。
2. **文本**：填美区 Apple ID 邮箱。
   重命名为 `美区账号`。
3. **从菜单中选取**：提示语填 `切换到哪个区？`，选项填两个：
   - `🇺🇸 美区`
   - `🇨🇳 国区`
4. 在 **🇺🇸 美区** 分支下添加：
   - **拷贝至剪贴板**：内容选 `美区账号`
   - **显示通知**：`已复制美区账号，在 App Store 退出后粘贴登录`
5. 在 **🇨🇳 国区** 分支下添加：
   - **拷贝至剪贴板**：内容选 `国区账号`
   - **显示通知**：`已复制国区账号，在 App Store 退出后粘贴登录`
6. 在菜单**结束之后**添加：
   - **打开 App**：选 `App Store`

做完后整体结构如下：

```
文本 (国区邮箱)            → 国区账号
文本 (美区邮箱)            → 美区账号
从菜单中选取 "切换到哪个区？"
├─ 🇺🇸 美区
│   ├─ 拷贝至剪贴板 [美区账号]
│   └─ 显示通知
└─ 🇨🇳 国区
    ├─ 拷贝至剪贴板 [国区账号]
    └─ 显示通知
结束菜单
打开 App [App Store]
```

## 使用方法

1. 运行快捷指令，选择目标地区。
2. App Store 打开后，点右上角**头像** → 滑到最底部 → **退出登录**。
3. 再点头像，在账号框里**粘贴**邮箱，密码用 Face ID 自动填充 → 登录。

> 也可以从“设置 → 你的名字 → 媒体与购买项目 → 退出登录”退出，效果一样，只会退出 App Store 账号，不影响 iCloud。

## 更快地触发

- **主屏幕**：快捷指令长按 → 分享 → 添加到主屏幕。
- **轻点背面**：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选这个快捷指令。
- **控制中心**（iOS 18 及以上）：下拉控制中心 → 左上角 `+` → 添加控制 → 快捷指令 → 选这个快捷指令。
- **Siri**：直接说“切换 App Store 地区”。

## 常见问题

**切换后已安装的 App 会被删除吗？**
不会。App 跟着下载它的账号走，更新时会提示输入那个账号的密码。

**美区账号能用来付费吗？**
需要美区的付款方式，比如美区礼品卡。切到美区账号后可以在 App Store 里兑换礼品卡。

**为什么不直接把密码写进快捷指令？**
就算写了，快捷指令也没法替你自动填进登录框，只会多一份明文密码的泄露风险。
